# 本地DLL注入 + AI自动做题功能说明

## 🎯 主要更新

### 1. 本地DLL注入（不再从服务器下载）

**变更内容：**
- 移除了从服务器下载DLL的功能
- 改为使用本地DLL文件进行注入
- 支持自动检测和手动选择DLL文件

**使用方法：**

#### 方法一：自动检测（推荐）
1. 将 `winmm.dll` 文件放置在注入器程序同目录下
2. 程序会自动检测并使用该DLL文件

#### 方法二：手动选择
1. 在第二界面点击"选择DLL..."按钮
2. 选择您的 `winmm.dll` 文件
3. 路径会自动保存到配置文件中

**DLL文件查找顺序：**
1. 使用配置文件中保存的DLL路径
2. 如果未配置，自动检测注入器同目录下的 `winmm.dll`
3. 检查目标程序目录是否已存在DLL

**注意事项：**
- DLL文件必须存在且大小不为0
- 首次使用需要手动提供DLL文件
- DLL路径会保存在 `ai_config.ini` 的 `[Injector]` 部分

---

### 2. AI自动做题功能

**新增功能：**
- ✨ 剪贴板自动监听
- ✨ 自动识别题目并调用AI解答
- ✨ 一键复制答案到剪贴板
- ✨ 实时监控，无需手动操作

**使用方法：**

#### 启动自动监听
1. 打开"AI答题助手"窗口
2. 勾选"自动监听剪贴板"复选框
3. 开始监听（每1秒检查一次剪贴板）

#### 工作流程
1. 复制题目文本到剪贴板（Ctrl+C）
2. 程序自动检测到新内容
3. 自动填入题目框并调用AI
4. AI解答完成后显示在答案区
5. 可点击"复制答案"将结果复制回剪贴板

#### 手动模式
1. 在"输入题目"框中粘贴或输入题目
2. 点击"AI解答 (F5)"按钮或按F5键
3. 等待AI响应并查看答案

**快捷键：**
- `F5` - 快速调用AI解答当前题目

**智能特性：**
- 自动去除文本前后空白字符
- 避免重复处理相同内容
- 忙碌时自动跳过新请求（防止重复）
- 关闭窗口自动停止监听

## 📁 配置文件

配置文件位置：`ai_config.ini`（与程序同目录）

```ini
[AI]
Endpoint=https://api.openai.com/v1/chat/completions
ApiKey=your-api-key-here
Model=gpt-3.5-turbo

[Settings]
AutoHide=1

[Injector]
DllPath=C:\Path\To\Your\winmm.dll
```

## 🔧 技术实现

### 本地DLL注入实现
1. **配置加载**：从 `ai_config.ini` 读取DLL路径
2. **自动检测**：若未配置，检测注入器目录下的 `winmm.dll`
3. **路径验证**：确保DLL文件存在且有效
4. **智能复制**：
   - 如果源路径与目标路径相同，无需复制
   - 否则复制DLL到目标程序目录
5. **自动清理**：目标程序退出后自动删除复制的DLL

### AI自动做题实现
1. **定时器监听**：使用 `WM_TIMER` 定时检查剪贴板（1秒间隔）
2. **内容比较**：与上次内容对比，避免重复处理
3. **异步调用**：使用线程异步调用AI API
4. **状态管理**：busy标志防止并发请求
5. **自动清理**：窗口销毁时自动停止定时器

## 🐛 常见问题

### Q1: 提示"找不到本地DLL文件"？
**A**: 
- 检查 `winmm.dll` 是否在注入器同目录
- 或点击"选择DLL..."手动选择
- 确保DLL文件大小不为0

### Q2: AI自动监听不工作？
**A**:
- 确保已勾选"自动监听剪贴板"
- 检查AI配置是否正确
- 查看是否有API Key
- 尝试手动解答测试

### Q3: DLL注入失败？
**A**:
- 确保以管理员身份运行（如需要）
- 检查DLL文件是否有效
- 查看日志文件了解详细错误

### Q4: 自动监听频率太高/太低？
**A**:
- 当前为1秒检查一次
- 如需调整，修改源码中的定时器间隔
- `SetTimer(hWnd, IDT_AI_CLIPBOARD, 1000, nullptr);`
