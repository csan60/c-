# 本地DLL注入器 + AI自动做题 (CxExam为例)

## 简介
一些外挂的运行模式--注入器模式，本程序作为一个示例以CxExam为例，展示如何实现**本地DLL注入**功能。

DLL文件来源于[cef_cx_copy_tool](https://github.com/SJYssr/cef_cx_copy_tool)

## ⚡ 重要更新 v3.0
- 🔥 **改用本地DLL注入**（不再从服务器下载）
- 🤖 **AI自动做题功能**（剪贴板自动监听）
- 🎯 **完全离线运行**（DLL部分无需网络）

## 技术解析
注入器启动后找目标文件，使用**本地DLL文件**注入到目标程序，监听目标程序，目标程序关闭后清理资源。

## 功能

- ✅ 支持手动定位或自动查找目标文件
- 🔧 **本地DLL注入**（不依赖服务器）
- 📁 支持手动选择DLL文件路径
- 🤖 **AI自动做题助手**（剪贴板监听）
- 🎭 支持自动隐藏到系统托盘
- 🧠 集成AI答题助手（OpenAI、DeepSeek等）
- 🔄 启动后可选自动隐藏并监听目标进程
- 🧹 目标进程结束后自动清理资源

## 使用说明

### 准备工作
1. 将 `winmm.dll` 文件放置在注入器程序同目录下
   - 或稍后通过"选择DLL..."按钮手动选择

### 基本使用
1. 启动程序，输入验证码进入主界面
2. 选择 CXExam.exe 文件的路径：
   - 点击"浏览..."手动选择文件
   - 或点击"自动查找"让程序自动搜索
3. [可选] 点击"选择DLL..."选择您的 winmm.dll 文件
4. 点击"启动"按钮：
   - 程序会使用本地DLL进行注入
   - 启动目标系统
   - 主程序可自动隐藏到托盘
5. 目标程序关闭后，注入器会自动清理资源

### AI自动做题
1. 点击"AI答题助手"打开助手窗口
2. 勾选"自动监听剪贴板"
3. 复制题目文本（Ctrl+C）
4. AI自动解答并显示答案
5. [可选] 点击"复制答案"将结果复制回剪贴板

详细使用说明请查看：[LOCAL_DLL_README.md](LOCAL_DLL_README.md)
