### 2. AI自动做题功能

#### 代码修改
- **新增结构体成员**
  - `AiHelperContext::autoMode` - 自动模式标志
  - `AiHelperContext::lastClipboard` - 上次剪贴板内容

- **新增控件**
  - "自动监听剪贴板" 复选框
  - "复制答案" 按钮

- **新增函数**
  - `TrimString()` - 去除字符串前后空白
  - `ReadClipboardText()` - 读取剪贴板文本
  - `WriteClipboardText()` - 写入文本到剪贴板

- **定时器监听**
  - 使用 `WM_TIMER` 定时检查剪贴板（1秒间隔）
  - 自动检测新题目并触发AI解答
  - 智能去重，避免重复处理

#### 工作流程
1. 用户勾选"自动监听剪贴板"
2. 启动定时器（每1秒检查一次）
3. 检测剪贴板内容变化
4. 自动填入题目框
5. 触发AI解答
6. 显示答案
7. 用户可一键复制答案
